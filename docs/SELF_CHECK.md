## 潛在風險與對策

| 風險 | 對策 |
|------|------|
| Grok 生成失敗或圖片風格不一致 | 所有 UI 都有 emoji/CSS fallback，遊戲不依賴圖片可玩 |
| iOS 首次載入無聲音 | 需使用者手勢觸發 AudioContext，已在程式內處理 |
| 2 歲幼童誤點 | 所有「危險」按鈕（退出、重置）均需長按 / 無 |
| 小朋友無限重玩 | 每日任務限制 + 視覺化「今天完成」狀態 |
| 時段限制讓小孩失望 | 關閉時段顯示可愛「月亮睡覺」插畫而非錯誤 |
| 橫/直切換跑版 | CSS Grid 自適應 + 媒體查詢 |
| 離線/無網路 | Service Worker cache-first 策略 |

## 結論

**設計通過自我檢查，可以進入實作階段。**
