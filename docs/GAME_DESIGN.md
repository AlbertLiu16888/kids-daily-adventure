# 仙貝與旺旺龍的每日探險 (Kids Daily Adventure)

## 遊戲概述

**目標玩家**：仙貝（3.5 歲女童）、旺旺龍（2 歲男童）
**遊戲類型**：日常探索 × 互動養成 × 拖移小遊戲
**核心循環**：每日進入一個地點 → 完成 3 個任務 → 獲得糖果獎勵 → 收集到背包

## 設計原則

1. **大圖示、大按鈕**：最小觸控區域 80×80 px，主地圖地點圖示 120×120 px。
2. **少文字、重音效**：所有互動都配合語音提示（中文）與音效。
3. **不處罰、不倒數**：任務沒有失敗機制，只有完成/未完成。
4. **拖移為主**：2 歲也能操作，把道具拖到動物/人物身上觸發動畫。
5. **每日一次**：每個任務 24 小時內只能做一次（當地時間 00:00 重置），避免過度使用。
6. **時間窗**：不同地點有不同開放時段，培養時間感。

## 地點任務詳細

### 1. 青塘園 🦆（綠色糖果）
時段：08:00–21:00
- **任務 A — 餵鴨鵝**：拖「麵包」到鴨子鵝 → 動物跑來啄食，開心振翅 🐤
- **任務 B — 餵魚**：拖「魚飼料」撒到水面 → 魚群聚集、水面泛起漣漪 🐟
- **任務 C — 跟狗玩**：拖「飛盤」丟給狗 → 狗叼飛盤跑回來，搖尾巴 🐕

**道具**：🍞 麵包、🐟 魚飼料、🥏 飛盤

### 2. 田園幼稚園 🏫（黃色糖果，仙貝主場）
時段：08:00–12:00
- **任務 A — 自己吃飯**：拖「湯匙」到「飯碗」→ 角色大口吃飯 → 清空碗盤 🍚
- **任務 B — 自己刷牙**：拖「牙刷」到「牙膏」→ 角色刷牙泡泡動畫 🦷
- **任務 C — 學腳踏車**：拖「安全帽」戴上 → 角色騎車搖晃前進 🚴

**道具**：🥄 湯匙、🪥 牙刷+牙膏、⛑️ 安全帽

### 3. 金培恩托兒所 🧸（橘色糖果，旺旺龍主場）
時段：08:00–12:00
- **任務 A — 自己吃飯**：拖「奶瓶」到角色嘴邊 → 咕嚕咕嚕喝完 🍼
- **任務 B — 自己洗手**：拖「肥皂」到水龍頭下 → 搓泡泡動畫 🧼
- **任務 C — 收玩具**：拖玩具到玩具箱（3 件）→ 玩具蓋子關上 ✨

**道具**：🍼 奶瓶、🧼 肥皂、🧸 積木/小車/娃娃

### 4. 海邊 🏖（藍色糖果）
時段：08:00–21:00
- **任務 A — 堆沙堡**：拖「沙桶」到沙灘 3 次 → 城堡慢慢長高 🏰
- **任務 B — 踏浪**：點擊海浪 5 次 → 浪花飛濺、腳印留在沙上 👣
- **任務 C — 抓螃蟹**：拖「水桶」蓋住螃蟹 → 螃蟹被裝進桶中（3 隻）🦀

**道具**：🪣 沙桶、🕳️ 小鏟子、🪣 透明水桶

### 5. 恐龍山 🦖（紅色糖果）
時段：08:00–21:00
- **任務 A — 餵恐龍吃肉**：拖「肉肉」給恐龍 → 恐龍張嘴咬、開心搖尾 🍖
- **任務 B — 爬山健身**：點階梯 10 次 → 角色爬到山頂、出現雲朵 ⛰️
- **任務 C — 關恐龍回籠**：拖「籠子」套住亂走的小恐龍（3 隻）→ 恐龍在籠裡開心跳 🎪

**道具**：🍖 肉肉、🥾 登山鞋、🏚 籠子

### 6. 辦公室 💼（紫色糖果）
時段：12:00–18:00
- **任務 A — 陪爸爸打電腦**：拖「鍵盤」到電腦 → 螢幕出現彩色文字 💻
- **任務 B — 陪鴨子散步**：拖「牽繩」綁在鴨子上 → 鴨子跟著走一圈 🦆
- **任務 C — 玩布穀鳥時鐘**：點時鐘 → 布穀鳥跳出、發出「咕咕」聲 🕰

**道具**：⌨️ 鍵盤、🪢 牽繩、🕰 布穀鳥時鐘

## 獎勵系統

- 完成單一任務 → 小星星動畫 + 愉悅音效
- 完成一個地點的所有 3 個任務 → 獲得一顆該色糖果，落入背包
- 6 顆糖果全收集 → 彩虹動畫 + 特別音樂（「彩虹糖果大滿貫！」）
- 背包頁面可以看到累計糖果數量（以日計算、總計兩種顯示）

## 輸入/互動規範

- **拖移**：支援滑鼠與觸控（pointer events）
- **點擊**：所有地點圖示、道具圖示、返回按鈕
- **震動**：支援 `navigator.vibrate`（Android / Chrome），iOS 走 WebAudio 震動替代
- **音效**：
  - 背景音樂（每個地點不同，循環播放，可關閉）
  - 互動音效（點擊「咚」、成功「叮」、完成任務「耶！」）
  - 語音提示（中文短句，例：「把麵包給鴨子！」「你好棒！」）

## 響應式設計

- **直式手機**（最常見）：主視圖垂直卡片，地點 2×3 grid
- **橫式手機/平板**：地點 3×2 grid，場景擴展為寬版
- **桌機**：置中 max-width 1024px，以免過度拉伸
- **Safe area**：支援 iPhone 瀏海/底部手勢區
- **最小尺寸**：320 × 568（iPhone SE）

## 儲存

使用 `localStorage`：
- `kda_candies`：糖果收藏（每色數量）
- `kda_daily_{YYYY-MM-DD}`：當日已完成任務 ID 陣列
- `kda_settings`：音量、語言、音樂開關
- `kda_last_visit`：上次進入時間（決定是否需要新一天重置）

## 無障礙與安全

- 不需註冊、無網路亦可玩（PWA）
- 無內購、無廣告
- 無文字輸入需求
- 無外連（所有資源打包本地）

## 技術棧

- Pure HTML5 + CSS3 + Vanilla JS（ES modules）
- Web Audio API（音效/BGM）
- Pointer Events（拖移）
- Vibration API（震動）
- localStorage（進度）
- 單頁應用，可直接部署 GitHub Pages
